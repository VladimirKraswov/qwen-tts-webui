# Qwen TTS Web UI

Веб-интерфейс для синтеза речи на базе Qwen3-TTS.

## Возможности

- 🎙️ Синтез речи с выбором голоса и языка
- 💾 Возврат MP3, WAV или PCM
- ⚡ PCM-стриминг чанками
- 📖 Загрузка `.txt` и пакетная озвучка книги по абзацам
- 🧪 Заглушка под обучение новых голосов

## Запуск

1. Установите Docker и NVIDIA Container Toolkit.
2. Соберите и запустите проект:

```bash
docker compose up --build
